# OpenCode Global Guidance

Shared policy is loaded from `config/ai/global-policy.md` through the OpenCode
`instructions` configuration.

Use the OpenCode tool and skill interfaces to select specialized workflows;
their metadata is the current source of truth for available capabilities.

When creating or changing agent-facing instructions, skills, commands, or
agent prompts, read
`~/.dotfiles/config/opencode/references/writing-for-agents.md` first.
