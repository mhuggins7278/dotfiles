Own the **unclear idea to aligned** transition from
`~/.dotfiles/config/ai/playbooks/workflow.md`.

Run a `/grilling` session using the `/domain-modeling` skill. Resolve decisions
one at a time, update `CONTEXT.md` and ADRs as decisions land, and summarize
what is resolved and what remains open.

Do not publish a spec or create tickets. When the user confirms the idea is
aligned, hand off to `to-spec`.
