# AI Configuration

The shared policy is intentionally concise because it is loaded into every
OpenCode session. Detailed, conditional guidance belongs in the relevant
workflow, skill, agent, or repository instructions.

The policy is a local adaptation of the [Clanker Constitution
v2026.08.11](https://github.com/kenn-io/constitution/tree/v2026.08.11), by Wes
McKinney and Kenn Software LLC, licensed under [CC BY
4.0](https://creativecommons.org/licenses/by/4.0/).
